# Batalha Munduruku vs. Muirapinima — V2.2: Trilhas da Amazônia

## Publicação no GitHub Pages

1. Extraia o ZIP antes de fazer o upload.
2. Entre no repositório do jogo no GitHub e selecione **Add file > Upload files**.
3. Envie o arquivo `index.html` para a **raiz** do repositório. Este pacote também inclui `jogar-v22.html` como cópia para teste isolado.
4. Faça **Commit changes**. Abra **Settings > Pages > Deploy from a branch**, `main` e `/(root)`.
5. Acesse a URL do GitHub Pages do repositório. Se o navegador guardar a versão antiga, recarregue ignorando o cache.

## Novidades

- Campanha de cinco capítulos: Cartógrafo da Floresta, Suprimentos da Jornada, As Margens do Grande Rio, A Chamada do Trovão e O Primeiro Guardião.
- Minimapa com marcador de destino e mapa detalhado; objetivos renderizados no cenário.
- Coleta e fabricação de ração, tocha, repelente e curativo *exclusivamente fictícios*; consumo simulado de comida/água.
- Marcadores e recursos extras no caminho das missões; missões com XP e diário.
- Salva automaticamente na chave local `batalha-v22-trilhas-v1`, separado da V2.1.1 (`batalha-v21-preview-v1`). Quando possível, importa automaticamente o progresso local da versão anterior.
- Exportar/importar manualmente um salvamento V2.2 em JSON para troca entre dispositivos.

## Limitações honestas

É uma evolução da **prévia 2D V2.1.1**, **não uma fusão com a base V1.9** e **não é 3D fotorrealista**. Os controles, bestiário, personagens e criaturas são estilizados. Multiplayer, personagens realistas tipo PUBG, travessia de rios e integração integral de todos os recursos da V1.9 permanecem para versões futuras. Os itens de sobrevivência são *mecânicas ficcionais*, não recomendações médicas ou de campo.

## Controles

Celular: direcional, Observar/Coletar, Atacar Guardião, Usar Curativo, botão MAPA e MOCHILA.
Teclado: WASD/setas, E (coletar/observar), Espaço (atacar), H (curativo), B (bestiário), I (mochila).

## Observação de autoria

Esta é uma aventura **fictícia** inspirada nos ambientes de Juruti e em motivos fantásticos. Ela não deve ser tomada como representação de crenças, tradições ou narrativas oficiais de povos indígenas.
